최종 상품 상세 설정

건물 구성에 맞게 레벨, 건물 수, 행복도를 입력하세요. 상세 설정을 사용하면 기본 표의 레벨·건물 수·행복도는 상세 구성에 따라 자동 표시됩니다. 행복도는 최종 상품 생산량에만 반영되며 중간 자원 사용량에는 영향을 주지 않습니다.
1. 불가사의와 보너스 적용 레벨을 입력하면 기초 자원 보너스가 자동 반영됩니다. 일괄 운영 시간은 일반 설정과 상세 설정에서 운영 시간을 비워둔 경우 적용됩니다.
2. 기초 자원은 현재 보유량과 예상 생산량을 기준으로 필요한 금화·낙타의 충족 여부와 소요 시간을 계산합니다. 소요 시간(h)은 현재 보유량을 포함하여 부족한 기초 자원이 처음 ‘잔여’가 되기까지 필요한 운영 시간입니다.
3. 중간 자원은 현재 보유량을 반영하여 실제 구매 필요량과 금화·낙타 필요량을 계산합니다.
4. 최종 상품의 설정을 기준으로 예상 생산량과 중간 자원 사용량을 계산합니다.

2. 수면 대비 자원 확보는 수면까지 남은 시간(h) 동안의 최종 상품 생산에 사용되는 중간 자원, 중간 자원의 현재 보유량, 금화·낙타의 현재 보유량을 함께 반영하여 수면 중 필요한 중간 자원을 구매하기 위한 생산력을 계산합니다.
3. 목표 레벨 생산력 비교는 현재 생산력과 목표 레벨 달성에 필요한 생산력을 비교하여 생산력 차이를 계산합니다. 최종 상품 부족분을 추가 생산할 때 늘어나는 중간 자원 구매 비용까지 반영하여 금화·낙타 필요 생산력을 계산합니다.
※ 생산력은 행복도 100%의 Lv6 건물 1개를 100으로 둔 지수입니다. 현재 생산력은 현재 설정된 건물 구성의 생산 능력을 나타내며, 필요 생산력은 각 계산에서 현재 보유량을 고려해 목표를 충족하는 데 필요한 생산 능력을 환산한 값입니다.
